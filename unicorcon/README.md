# UNICORCON PERÚ — Sitio web

Sitio web responsive de una sola página, construido con HTML, CSS y JavaScript independientes.

## Estructura
- `index.html` — estructura y contenido por secciones.
- `css/styles.css` — estilos, responsive y componentes.
- `js/main.js` — menú móvil, animaciones de entrada y formulario a WhatsApp.
- `assets/` — imágenes optimizadas (WebP) extraídas del brochure corporativo.

## Secciones
Hero · Nosotros · Historia y propósito · Respaldo y certificaciones · Productos y soluciones · Servicios · ¿Por qué elegirnos? · Contacto.
